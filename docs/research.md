# STEEL CLIMBER 1981 — 사전 조사

1980년대 초 오락실의 **세로형 등반 플랫폼 게임**이 어떤 규칙과 감각으로 굴러갔는지를 정리하고,
그중 무엇을 그대로 가져오고(플레이 규칙) 무엇을 새로 만들었는지(모든 표현·수치·배치)를 구분한다.

표기 규칙

| 표기 | 뜻 |
|---|---|
| `[자료]` | 공개된 하드웨어 사양·플레이 가이드 등으로 확인 가능한 역사적 사실 |
| `[구현 추정]` | 원작 내부값을 알 수 없어 "그 감각이 나도록" 이 게임에서 직접 정한 수치 |
| `[독자적 변경]` | 원작과 구별하기 위해 의도적으로 다르게 만든 부분 |

> 이 문서는 **장르 연구 노트**다. 특정 상용 게임의 상표·캐릭터·스프라이트·음원·소스코드·스테이지 좌표는
> 조사 대상이 아니며 이 프로젝트 어디에도 복제하지 않는다. 참고한 자료의 출처는 문서 맨 아래에 URL로만 남긴다.

## 1. 화면과 해상도

- `[자료]` 1981년의 대표적인 세로형 등반 게임은 Z80 계열 기판에 **세로로 세운 래스터 모니터**를 썼고,
  내부 해상도는 **224 × 256 픽셀**(가로 224 / 세로 256)이었다.
- `[자료]` 사운드는 메인 CPU와 별개인 보조 사운드 CPU + 디스크리트 회로로 만든 단순 전자음이었다.
  샘플 재생이 아니라 **파형을 즉석에서 만들어 내는 방식**이라 소리가 짧고 건조하다.
- `[구현 추정]` 이 게임도 내부 좌표계를 **224 × 256 고정**으로 잡고, 캔버스 백버퍼를 정확히 그 크기로 둔다.
  화면에 보이는 크기는 CSS가 정수배로 확대하므로 **표시 크기가 변해도 충돌 좌표는 절대 변하지 않는다.**
- `[구현 추정]` 상단 26px을 HUD로 쓰고 나머지 230px이 플레이 영역이다.

## 2. 좌우 이동과 관성

- `[자료]` 당시 조작은 4방향 레버 + 버튼 1개다. 아날로그 입력이 없으므로 이동은 **켜짐/꺼짐 두 상태**뿐이다.
- `[자료]` 캐릭터는 미끄러지지 않는다. 레버를 놓으면 즉시 선다. 현대 플랫폼 게임의 가속·감속 곡선이 없다.
- `[구현 추정]` 걷기 속도 **52 px/s**. 화면 폭 224px을 가로지르는 데 약 4.3초로, 당시 체감과 비슷하다.
- `[구현 추정]` 관성 0. 입력이 끊기면 그 프레임에 속도가 0이 된다.

## 3. 점프

- `[자료]` **점프 거리와 높이가 고정**이며, **공중에서 방향을 바꿀 수 없다.** 뛰기 전에 미리 거리를 계산해야 한다.
  이 제약이 "장애물을 아슬아슬하게 넘는" 긴장감의 핵심이다.
- `[자료]` 제자리 점프도 유효한 회피 수단이고, 장애물을 넘으면 보너스 점수가 붙는다.
- `[구현 추정]` 초기 상승속도 **-125 px/s**, 중력 **520 px/s²**.
  → 정점 높이 약 15px, 체공 약 0.48초, 이동 중 점프 시 수평 이동 약 25px.
  드럼통(지름 10px)을 넘기에 충분하되 두 개가 붙어 오면 못 넘는 값으로 맞췄다.
- `[구현 추정]` 점프 중에는 이륙 시점의 수평 속도가 **고정**된다(공중 조작 없음). 원작의 감각을 그대로 살린 부분이다.

## 4. 경사 발판과 장애물의 굴러감

- `[자료]` 1스테이지의 발판은 **좌우로 번갈아 기울어진 여러 층**이고, 장애물은 경사가 낮은 쪽으로 굴러간다.
- `[자료]` 장애물은 발판의 낮은 쪽 끝에 도달하면 **아래층으로 떨어져** 반대 방향으로 다시 굴러간다.
  결과적으로 화면 전체를 지그재그로 훑는다.
- `[구현 추정]` 발판을 **꺾인 선(폴리라인)** 으로 표현한다. 한 발판이 여러 기울기 구간을 가질 수 있어
  단순한 직선 경사보다 다양한 배치를 만들 수 있다.
- `[구현 추정]` 드럼통 기본 속도 **42 px/s**, 경사가 가파를수록 최대 1.55배까지 빨라진다.
- `[독자적 변경]` 원작의 철골 좌표·기울기·사다리 위치를 참고하지 않고 이 게임만의 층 배치를 새로 설계했다.
  층 간격 30px, 6개 층 + 최상단 목표 발판 구조이며, 3층에는 원작에 없는 **두 단 꺾임 경사**를 넣었다.

## 5. 장애물의 사다리 하강

- `[자료]` 굴러오던 장애물은 사다리 위를 지나갈 때 **일정 확률로 사다리를 타고 아래층으로 내려간다.**
  이 때문에 플레이어는 사다리를 오르는 중에도 위층을 살펴야 한다.
- `[자료]` 원작에는 레버 입력이 장애물의 사다리 선택에 영향을 준다고 알려진 동작이 있다.
- `[구현 추정]` 사다리 중심 ±3px 안에 들어오면 판정한다. 기본 확률 **28%**.
- `[독자적 변경]` "레버로 유도" 대신, **플레이어가 그 사다리 아래쪽 가까이에 있으면 확률이 올라가는**(최대 +22%p)
  독자적인 규칙을 넣었다. 결과적인 압박감은 비슷하되 동작 원리는 다르다.
- `[구현 추정]` 확률 판정은 시드 지정 가능한 난수기(mulberry32)로 하고, 테스트에서 시드를 고정할 수 있게 한다.

## 6. 사다리 오르내리기와 진입 판정

- `[자료]` 사다리는 위층 발판과 아래층 발판을 잇는다. 사다리 위쪽 끝에서는 **발판 위로 올라선다.**
- `[자료]` **끊어진 사다리**가 존재하며, 아래에서 어느 높이까지만 올라갈 수 있고 통과는 못 한다.
- `[구현 추정]` 사다리 중심 **±4px** 안에 있을 때만 진입한다(스프라이트 폭 12px보다 좁게 잡아 오작동을 줄인다).
- `[구현 추정]` **점프·낙하 중에는 사다리에 붙지 않는다.** 발판 위에 서 있거나 이미 사다리에 매달린 상태여야 한다.
- `[구현 추정]` 오르기 속도 **38 px/s**. 걷기보다 느려서 "사다리 위는 위험하다"는 감각이 생긴다.
- `[구현 추정]` 사다리 상단 진입: 발판 위에서 ↓를 누르고 사다리 중심 근처면 매달린다.
  하단 진입: 발판 위에서 ↑. 상단 이탈: 몸통이 위층 표면보다 올라가면 그 발판에 선다.

## 7. 낙하와 사망

- `[자료]` 일정 높이 이상 떨어지면 죽는다. 한 층 정도의 낙차는 안전하다.
- `[구현 추정]` 낙하 거리 **34px 초과**면 착지 순간 사망. 층 간격이 30px이므로 한 층은 안전하다.
- `[구현 추정]` 사망 연출 1.4초(회전 후 쓰러짐) → 생명 감소 → 스테이지 재시작.

## 8. 해머(원작의 반격 아이템에 해당)

- `[자료]` 맵의 고정 위치에 있고, 닿으면 **자동으로 일정 시간 활성화**된다. 직접 끄지 못한다.
- `[자료]` 활성화 중에는 **점프와 사다리 이동을 할 수 없다.** 강력한 대신 이동이 제한되는 교환 조건이다.
- `[자료]` 앞쪽과 위쪽을 번갈아 때리는 **2프레임 애니메이션**이고, 닿은 장애물이 파괴되며 점수가 들어온다.
- `[구현 추정]` 지속 **9초**. 남은 2.5초부터 깜빡임 + 경고음.
- `[구현 추정]` 타격 판정은 프레임에 따라 앞(12×10) / 위(10×12) 두 상자를 번갈아 쓴다. 0.14초마다 전환.
- `[독자적 변경]` 명칭과 외형을 **전동 브레이커(해머 드릴)** 로 바꿨다.

## 9. 이동형 적(원작의 불꽃 계열에 해당)

- `[자료]` 특정 장치에서 생성되어 발판 위를 돌아다니며 플레이어를 **느리게** 쫓는다. 사다리도 오르내린다.
- `[자료]` 완벽하게 추적하지 않고 어긋나기 때문에 유인해서 따돌릴 수 있다.
- `[구현 추정]` 이동 속도 **26 px/s**(플레이어의 절반). 0.55초마다 한 번씩만 방향을 재판단하고,
  목표 x에 **±10px 오차**를 준다. 사다리를 만나면 40% 확률로 층을 바꾼다.
- `[독자적 변경]` **용접 불꽃**으로 바꿨다. 바닥의 용접기에 드럼통이 떨어지면 생성된다.

## 10. 제한시간(BONUS)과 점수

- `[자료]` 스테이지마다 보너스 값이 있고 시간이 지나면 계속 줄어든다. 0이 되면 죽는다.
  스테이지를 깨면 **남은 보너스가 점수에 더해진다.**
- `[자료]` 일정 점수에 도달하면 생명이 하나 늘어난다.
- `[구현 추정]` 보너스 5000에서 시작, **0.75초마다 100 감소** → 한 스테이지 제한시간 약 37초.
- `[독자적 변경]` 점수표는 원작 값을 쓰지 않고 전부 새로 정했다.

  | 행동 | 점수 |
  |---|---|
  | 드럼통 1개 뛰어넘기 | 120 |
  | 2개 동시 | 320 |
  | 3개 이상 동시 | 700 |
  | 해머로 드럼통 파괴 | 350 |
  | 해머로 용접 불꽃 제거 | 550 |
  | 안전조끼 | 400 |
  | 공구함 | 600 |
  | 도면통 | 900 |
  | 안전핀 1개 해제 | 150 |
  | 스테이지 완료 | 남은 BONUS 전액 |
  | 추가 생명 | 12,000점 도달 시 1회 |

- `[구현 추정]` 같은 장애물에 점프 점수를 **두 번 주지 않도록** 장애물마다 지급 여부 플래그를 둔다.

## 11. 스테이지 구성과 난이도 상승

- `[자료]` 큰 스테이지 하나가 **성격이 다른 네 개의 단일 화면**으로 이루어져 있고,
  네 개를 다 깨면 처음으로 돌아가되 더 어려워진다.
  네 화면의 성격은 (1) 경사 발판 (2) 운반장치 (3) 승강 구조 (4) 고정장치 제거 이다.
- `[자료]` 난이도가 오르면 장애물이 더 빨리, 더 자주 나온다.
- `[구현 추정]` 루프마다 장애물 속도 ×1.12(상한 1.8), 생성 간격 ×0.9(하한 0.6),
  불꽃 최대 개수 +1(상한 4), 시작 보너스 -500(하한 3000). **무한히 어려워지지 않게 상한을 둔다.**
- `[독자적 변경]` 네 스테이지의 배치·장치 형태·목표물은 전부 새로 설계했다.

## 12. 연출과 사운드

- `[자료]` 스프라이트 애니메이션은 2~4프레임으로 짧고, 동작의 시작과 끝이 분명하다.
- `[자료]` 효과음은 0.1초 안팎으로 매우 짧고, 상승/하강하는 단순한 파형이다.
- `[구현 추정]` 모든 소리를 Web Audio API의 오실레이터·노이즈로 **코드에서 합성**한다. 음원 파일이 없다.
- `[독자적 변경]` 원작의 멜로디·음정·리듬을 쓰지 않고 자체 구성한 짧은 전자음을 사용한다.
- `[구현 추정]` CRT 효과는 약한 스캔라인 + 테두리 발광 + 미세한 번짐으로만 넣고, 끌 수 있게 한다.
