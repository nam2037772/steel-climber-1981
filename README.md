# STEEL CLIMBER 1981

> 1980년대 초 오락실의 **세로형 등반 플랫폼 게임**이 주던 감각을 다시 만들어 본 독자 제작 웹게임.
> 빌드 도구도 서버도 DB도 없는 완전한 정적 웹게임입니다.

고층 철골 공사현장. 폭주한 대형 양중 로봇이 구조물 꼭대기의 **비상정지 제어장치**를 점거했다.
안전모를 쓴 현장 기술자가 굴러 내려오는 철제 드럼통과 용접 불꽃을 피해 한 층씩 올라가
비상정지 장치를 눌러야 한다.

---

## 개발 목적

* 1981년 아케이드 게임의 **플레이 규칙과 조작감**이 왜 그렇게 설계됐는지 직접 만들어 확인해 보는 것
* 프레임워크·게임엔진·외부 자산 없이, 캔버스와 Web Audio만으로 어디까지 만들 수 있는지 확인하는 것
* 게임 규칙을 UI에서 분리해 **단위 테스트로 고정**하는 연습

개발·추억 재현용 게임입니다. 상업적 목적이 없고 검색 노출도 막아 두었습니다(`noindex, nofollow`).

## 저작권에 대하여

이 게임은 1980년대 초 세로형 등반 아케이드 게임 **장르의 플레이 방식**에서 영감을 받아 만든
**독립적인 오마주**입니다. 특정 상용 게임의 **상표·로고·캐릭터·스프라이트·음원·소스코드·스테이지 좌표를
사용하지 않았습니다.**

* 모든 그래픽은 [`src/render/sprites.js`](src/render/sprites.js) 안에 직접 그린 픽셀 데이터와 도형 코드입니다.
* 모든 소리는 [`src/io/audio.js`](src/io/audio.js) 에서 Web Audio API로 즉석 합성합니다. 음원 파일이 없습니다.
* 네 스테이지의 층 좌표·기울기·사다리 위치·점수표는 전부 이 프로젝트에서 새로 설계했습니다.
* 등장인물은 **안전모를 쓴 현장 기술자**와 **양중 로봇**이며, 원작의 캐릭터와 무관합니다.

조사한 내용과 "무엇을 참고했고 무엇을 새로 정했는지"는 [`docs/research.md`](docs/research.md)에
`[자료]` / `[구현 추정]` / `[독자적 변경]` 으로 구분해 정리했습니다.

## 조작법

### PC

| 키 | 동작 |
|---|---|
| `←` `→` 또는 `A` `D` | 좌우 이동 |
| `↑` `↓` 또는 `W` `S` | 사다리 오르내리기 |
| `Space` | 점프 |
| `X` (또는 `Z`) | 전동 브레이커 타격 방향 전환 (앞 ↔ 위) |
| `P` 또는 `Esc` | 일시정지 |
| `Enter` | 시작 · 게임 오버 후 재시작 |

### 모바일

화면 아래 방향 패드(`▲ ◀ ▼ ▶`)와 `JUMP` · `HIT` · `PAUSE` 버튼.
**멀티터치를 지원하므로 방향을 누른 채로 점프할 수 있습니다.**

### 알아 두면 좋은 것

* **공중에서는 방향을 바꿀 수 없습니다.** 뛰기 전에 거리를 계산해야 합니다. 의도한 제약입니다.
* **전동 브레이커를 들고 있는 동안에는 점프도 사다리도 불가능합니다.** 강력한 대신 이동이 묶입니다.
* 드럼통을 뛰어넘으면 점수가 붙습니다. 두 개를 한 번에 넘으면 훨씬 큽니다.
* 굴러오던 드럼통이 **사다리를 타고 내려오기도 합니다.** 사다리 중간에서 위층을 봐야 합니다.
* 끊어진 사다리는 위로 통하지 않습니다.
* `BONUS`가 0이 되면 죽습니다.

## 로컬 실행 방법

ES 모듈은 `file://` 에서 로드되지 않으므로 http로 띄워야 합니다.
의존성 없는 정적 서버가 들어 있습니다.

```bash
npm start              # http://localhost:8080
# 또는
node tools/serve.mjs 8080
```

GitHub Pages의 프로젝트 하위 경로 동작을 미리 확인하려면
`http://localhost:8080/steel-climber-1981/` 로도 접속할 수 있습니다.

## 테스트 방법

```bash
npm install            # @playwright/test (E2E용, 유일한 의존성)

npm run check          # 구문·모듈 로드 검사 + 단위 테스트
npm test               # 단위 테스트만 (node --test, 브라우저 불필요)
npm run test:e2e       # Playwright 데스크톱 + Pixel 5 모바일
npm run shots          # 주요 화면 캡처 → screenshots/
```

* 단위 테스트는 게임 규칙 모듈만 다루므로 브라우저 없이 Node에서 바로 돌아갑니다.
* 확률에 기대는 부분(드럼통의 사다리 하강, 불꽃의 판단 오차)은 시드를 고정할 수 있습니다.
  `?seed=1234` 로 접속하면 전개가 재현됩니다.
* 테스트용 창구 `window.__steel` 은 `localhost` 또는 `?e2e=1` 일 때만 열립니다.

설계 원칙 하나만 꼽자면: **`src/game/` 은 캔버스도 DOM도 모릅니다.**
소리와 화면은 `emit()` 으로 알리기만 하고 바깥에서 처리하므로,
게임 규칙 전체를 브라우저 없이 Node에서 그대로 검증할 수 있습니다.

### 화면 좌표에 대해

캔버스 백버퍼는 **224×256 고정**(당시 세로형 기판의 내부 해상도)이고,
CSS가 그것을 정수배로 확대합니다. 따라서 창 크기를 어떻게 바꿔도
**게임 좌표와 충돌 판정은 1픽셀도 달라지지 않습니다.**
발판도 충돌 판정에 쓰는 `surfaceYAt()` 을 그대로 써서 그리므로 그림과 판정이 어긋날 수 없습니다.

## 구현한 기능

**스테이지 (4화면 순환, 깰수록 어려워짐)**

1. **경사 철골** — 좌우로 번갈아 기울어진 6층 + 목표 발판. 드럼통이 지그재그로 내려오고
   일부는 사다리를 타고 내려온다. 끊어진 사다리 2개.
2. **자재 운반장치** — 가야 할 방향과 반대로 도는 벨트, 고정 발판 사이의 빈틈 점프, 용접 불꽃.
3. **승강 발판** — 계속 올라가는 순환 승강기 3대와 왕복 리프트 1대, 위에서 떨어지는 공구,
   화면 밖 낙하 처리.
4. **안전핀 해제** — 8개의 안전핀을 밟고 지나가면 그 발판 조각이 사라진다.
   전부 해제하면 로봇의 지지대가 무너지며 완료. 플레이어도 적도 사라진 자리를 지나갈 수 없다.

**규칙**

* 관성 없는 좌우 이동 / 고정 거리 점프 / 공중 조작 불가
* 경사면 추종, 발판 끝 낙하, 낙하 거리 34px 초과 시 사망
* 사다리 진입 판정(중심 ±4px, 발판 위에서만), 상·하단 전환, 끊어진 사다리
* 드럼통의 경사 이동·가속·낙하·사다리 하강, 케이블 릴, 자재, 낙하 공구
* 판단 간격 0.55초 + 오차 10px로 추적하는 용접 불꽃(및 2바퀴째부터 점검 드론)
* 전동 브레이커 — 9초 자동, 2프레임 타격 상자, `X`로 앞/위 전환, 경고 신호, 완전 초기화
* 점프 점수(중복 지급 방지, 동시 2·3개 보너스), 파괴 점수, 아이템 3종, 스테이지 완료 보너스
* BONUS 제한시간, 12,000점 추가 생명, 최고 점수 갱신 표시
* 난이도 상승과 **상한**(속도 ×1.8, 생성 간격 0.6배, 불꽃 5마리, 보너스 3000이 하한)

**셸**

* 타이틀 화면(점멸 `PRESS ENTER`, 점수표, 조작법, 최고 점수, START 버튼)
* 일시정지, 브라우저 포커스 상실·탭 비활성 시 자동 일시정지, 입력 고착 방지
* 멀티터치 모바일 조작, PC·모바일 반응형, 가로 넘침 없음
* CRT 효과(약한 스캔라인·테두리 발광·비네트) 켜기/끄기
* localStorage 저장: 최고 점수 · 음소거 · 음량 · CRT
* 새로고침 없는 재시작, GitHub Pages 하위 경로 호환, 콘솔 오류 없음

## 미구현 기능

의도적으로 넣지 않았거나 다음으로 미룬 것들입니다.

* **2인 교대 플레이** — 화면에 `1 PLAYER`만 있습니다.
* **스테이지 간 데모/막간 연출** — 스테이지 완료 시 짧은 패널만 뜹니다.
* **배경 음악** — 효과음만 있습니다. 당시 기판도 상시 BGM이 없는 경우가 많았습니다.
* **점수 순위표** — 최고 점수 1개만 저장합니다.
* **게임패드 지원** — 키보드와 터치만 지원합니다.
* **화면 회전(가로 모드) 최적화** — 세로 화면 기준으로만 배치했습니다.
* 케이블 릴은 드럼통보다 조금 빠른 변형일 뿐, 별도의 고유 행동이 없습니다.

## 알려진 문제 / 의도한 동작

* **점프 중 낮은 철골 밑을 지날 때 스프라이트가 위 철골과 겹쳐 보일 수 있습니다.**
  경사 철골은 한쪽 끝에서 위아래 간격이 22px까지 좁아지는데, 천장 충돌을 넣으면
  그 자리에서 드럼통을 넘을 수 없게 됩니다. 당시 게임도 같은 방식이라 **겹침을 허용**했습니다.
  플레이어를 철골보다 나중에 그려서 가려지지 않게만 했습니다.
* **공중에서 방향 전환이 안 됩니다.** 버그가 아니라 당시 감각을 살린 제약입니다.
* 3단계에서 승강기 점프를 놓치면 대개 죽습니다. 낙차가 커서 그렇고, 의도한 난이도입니다.
* 배경 탭에서는 브라우저가 `requestAnimationFrame`을 억제하므로 게임이 멈춥니다.
  자동 일시정지와 함께 동작하는 정상 동작입니다.
* 사운드는 **첫 사용자 입력 이후에만** 켜집니다(브라우저 자동재생 정책).
